= Actions API
:toc:
:toclevels: 3

== Overview
Endpoints for GitHub Actions: artifacts, cache, OIDC, permissions, secrets, self-hosted runners, variables, and workflows/runs.

== ArtifactApi
[cols="1,2,3", options="header"]
|===
| Method | Endpoint | Description
| GET | `/repos/{owner}/{repo}/actions/artifacts` | List artifacts for a repo
| GET | `/repos/{owner}/{repo}/actions/artifacts/{artifact_id}` | Get an artifact
| DELETE | `/repos/{owner}/{repo}/actions/artifacts/{artifact_id}` | Delete an artifact
| GET | `/repos/{owner}/{repo}/actions/artifacts/{artifact_id}/{archive_format}` | Download artifact
| GET | `/repos/{owner}/{repo}/actions/runs/{run_id}/artifacts` | List run artifacts
| GET | `/orgs/{org}/actions/artifacts` | List org artifacts
|===
*Models:* `Artifact`, `Artifacts`

== CacheApi
[cols="1,2,3", options="header"]
|===
| Method | Endpoint | Description
| GET | `/orgs/{org}/actions/cache/usage` | Org cache usage
| GET | `/orgs/{org}/actions/cache/usage-by-repository` | Org cache usage by repo
| GET | `/repos/{owner}/{repo}/actions/cache/usage` | Repo cache usage
| GET/DELETE | `/repos/{owner}/{repo}/actions/caches` | List/Delete caches by key
| GET/DELETE | `/repos/{owner}/{repo}/actions/caches/{cache_id}` | Get/Delete cache by ID
|===

== PermissionApi
[cols="1,2,3", options="header"]
|===
| Method | Endpoint | Description
| GET/PUT | `/orgs/{org}/actions/permissions` | Org action permissions
| GET/PUT | `/orgs/{org}/actions/permissions/repositories` | Enabled repos
| PUT/DELETE | `/orgs/{org}/actions/permissions/repositories/{repository_id}` | Enable/Disable repo
| GET/PUT | `/orgs/{org}/actions/permissions/selected-actions` | Allowed actions
| GET/PUT | `/orgs/{org}/actions/permissions/workflow` | Default workflow permission
| GET/PUT | `/repos/{owner}/{repo}/actions/permissions` | Repo action permissions
| GET/PUT | `/repos/{owner}/{repo}/actions/permissions/access` | Workflow access level
| GET/PUT | `/repos/{owner}/{repo}/actions/permissions/selected-actions` | Repo allowed actions
|===

== SecretApi
[cols="1,2,3", options="header"]
|===
| Method | Endpoint | Description
| GET | `/orgs/{org}/actions/secrets` | List org secrets
| GET | `/orgs/{org}/actions/secrets/public-key` | Get org public key
| GET/PUT/DELETE | `/orgs/{org}/actions/secrets/{secret_name}` | Manage org secret
| GET/PUT/PUT/DELETE | `/orgs/{org}/actions/secrets/{secret_name}/repositories` | Org secret repos
| GET | `/repos/{owner}/{repo}/actions/secrets` | List repo secrets
| GET | `/repos/{owner}/{repo}/actions/secrets/public-key` | Repo public key
| GET/PUT/DELETE | `/repos/{owner}/{repo}/actions/secrets/{secret_name}` | Manage repo secret
| GET | `/repos/{owner}/{repo}/actions/organization-secrets` | Org secrets accessible to repo
| GET/PUT/DELETE | `…/environments/{environment_name}/secrets/{secret_name}` | Env secrets
|===

== SelfHostedRunnerApi
[cols="1,2,3", options="header"]
|===
| Method | Endpoint | Description
| GET | `/orgs/{org}/actions/runners` | List org runners
| GET | `/orgs/{org}/actions/runners/downloads` | List runner apps
| POST | `/orgs/{org}/actions/runners/generate-jitconfig` | Create JIT config
| POST | `/orgs/{org}/actions/runners/registration-token` | Create registration token
| POST | `/orgs/{org}/actions/runners/remove-token` | Create remove token
| GET/DELETE | `/orgs/{org}/actions/runners/{runner_id}` | Get/Delete org runner
| GET/POST/PUT/DELETE | `/orgs/{org}/actions/runners/{runner_id}/labels` | Manage org runner labels
| GET/POST/PUT/DELETE | `/repos/{owner}/{repo}/actions/runners/…` | Same for repo runners
|===
*Models:* `Runner`, `RunnerLabel`, `RunnersResponse`, `RunnerApplication`, `RunnerToken`, `RunnerJitConfig`

== VariableApi
[cols="1,2,3", options="header"]
|===
| Method | Endpoint | Description
| GET/POST | `/orgs/{org}/actions/variables` | List/Create org variables
| GET/PATCH/DELETE | `/orgs/{org}/actions/variables/{variable_name}` | Manage org variable
| GET/PUT/PUT/DELETE | `/orgs/{org}/actions/variables/{variable_name}/repositories` | Manage selected repos
| GET/POST | `/repos/{owner}/{repo}/actions/variables` | List/Create repo variables
| GET/PATCH/DELETE | `/repos/{owner}/{repo}/actions/variables/{variable_name}` | Manage repo variable
| GET | `/repos/{owner}/{repo}/actions/organization-variables` | Org variables for repo
| GET/POST/GET/PATCH/DELETE | `/repos/{owner}/{repo}/environments/{environment_name}/variables/…` | Env variables
|===
*Models:* `Variable`, `VariablesResponse`, `CreateVariableRequest`

== WorkflowApi
[cols="1,2,3", options="header"]
|===
| Method | Endpoint | Description
| GET | `/repos/{owner}/{repo}/actions/workflows` | List workflows
| GET | `/repos/{owner}/{repo}/actions/workflows/{workflow_id}` | Get workflow
| PUT | `…/{workflow_id}/disable` | Disable workflow
| POST | `…/{workflow_id}/dispatches` | Create workflow dispatch
| PUT | `…/{workflow_id}/enable` | Enable workflow
| GET | `…/{workflow_id}/runs` | List workflow runs
| GET | `…/{workflow_id}/timing` | Get workflow usage
| GET | `/repos/{owner}/{repo}/actions/runs` | List workflow runs for repo
| GET/DELETE | `/repos/{owner}/{repo}/actions/runs/{run_id}` | Get/Delete workflow run
| POST | `…/{run_id}/cancel` | Cancel workflow run
| POST | `…/{run_id}/force-cancel` | Force cancel
| GET | `…/{run_id}/jobs` | List jobs for run
| DELETE/GET | `…/{run_id}/logs` | Delete/Download run logs
| POST | `…/{run_id}/rerun` | Re-run workflow
| POST | `…/{run_id}/rerun-failed-jobs` | Re-run failed jobs
| GET | `…/{run_id}/timing` | Get run usage
| GET | `/repos/{owner}/{repo}/actions/jobs/{job_id}` | Get job for workflow run
| GET | `…/jobs/{job_id}/logs` | Download job logs
| POST | `…/jobs/{job_id}/rerun` | Re-run job
|===
*Models:* `Workflow`, `WorkflowRun`, `WorkflowJob`, `WorkflowStep`, `WorkflowRunsResponse`, `WorkflowsResponse`, `JobsResponse`
